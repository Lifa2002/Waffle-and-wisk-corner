# 🧇 Waffle & Whisk Corner — Digital Ordering Platform

A modern, responsive, and interactive web-based ordering and customisation platform built for a local dessert business. This application allows customers to browse menus, build custom treats with real-time price calculations, manage an interactive shopping basket, and seamlessly submit formatted orders directly via WhatsApp.

🔗 **Live Demo:** [View Live on Netlify](https://waffleandwiskcorner.netlify.app/)

---

## ✨ Key Features

- **Interactive Menu & Customisation:** Dynamic product catalog with category filtering (Waffles, Waffle Pops, Crepes, Crepesushi, and Tacoffles) and real-time live price calculations based on selected add-ons.
- **Interactive Shopping Basket:** Fully functional shopping cart drawer allowing quantity adjustments, item removal, and subtotal/grand total calculations.
- **WhatsApp Order Integration:** Automatically formats a clean, itemized order receipt—complete with customer details, fulfillment type (Pickup/Delivery), and banking instructions—and routes it straight to the business WhatsApp chat.
- **Rich Media & UI Touches:** Integrated video previews, image carousels (powered by Swiper JS), celebratory confetti animations upon checkout completion, and mobile-friendly responsive design.
- **Store Operations Logic:** Built-in operating hours validation to manage store availability.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3
- **Styling:** Tailwind CSS (via CDN)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Libraries & Plugins:** 
  - [Swiper JS](https://swiperjs.com/) (for interactive media banners)
  - [FontAwesome](https://fontawesome.com/) (for icons)
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) (for success animations)
- **Version Control & Deployment:** Git, GitHub, Netlify

---

## 📱 How It Works

1. **Browse & Select:** Customers explore the menu, filter by category, or use the search bar to find specific treats.
2. **Customise:** Choose base items and select optional extra add-ons (biscuits, fresh fruit, sauces, whipped cream) with instant price updates.
3. **Checkout:** Enter name, contact number, and fulfillment preferences (Pickup or Delivery).
4. **WhatsApp Dispatch:** Clicking "Place Order via WhatsApp" automatically generates a structured order summary and opens WhatsApp to send it instantly to the vendor.
